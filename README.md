# HOOLA · 작은 카드 클럽

컴퓨터 3명과 플레이하는 한국어 HTML/JavaScript 훌라. 서버·설치·외부 라이브러리 없이 작동합니다.

## 실행
`index.html` 또는 `dist/index.html`을 브라우저로 엽니다. 또는 프로젝트에서 `python3 -m http.server 4173` 실행 후 http://localhost:4173 에 접속합니다.

## 플레이
더미에서 한 장 받기 → 카드 선택 후 등록/붙이기 → 한 장 선택 후 버리기. 땡큐 버튼은 버린 카드로 새 3장 조합이 만들어질 때 활성화됩니다. 힌트, 정렬, 새 게임, 결과표, 로컬 승패 기록을 제공합니다.

## 적용 규칙
일반(비전투) 훌라, 조커 없는 52장, 4인 각 7장. 같은 숫자 3~4장/동일 무늬 순환 연속 3장 이상/단독 7 등록. 등록 후 다른 묶음에 붙이기 가능. 땡큐는 내 차례에만, 버린 카드를 포함한 3장 즉시 등록. 받기 전 10점 이하 스톱, 선언자 동점 패배. A=1/J=11/Q=12/K=13/남은 7=14. 더미 소진은 마지막 수령자의 차례 종료 후 최소점 비교(동점 공동 승리). 소팡≤15·대팡≥83(7=7로 계산), 손의 7 네 장 특수 승리 지원. 다음 판은 승자부터. 베팅, 배수/독박 정산, 차례 밖 땡큐는 적용하지 않습니다.
